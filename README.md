This an emulator of the original GameBoy Nintendo handheld console developed entirely in C.

To run the emulator, all you need to do is download the latest version from the **Releases** tab and execute the .exe inside the .zip file. Select the game you want to play by clicking File->Open ROM, and enjoy!

You can customize the controls in Settings->Game Controls. These can be applied to the current game only or globally, as preferred. Other emulation settings can also be changed under Settings->Emulator.
